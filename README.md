# Лабораторная работа №1

## Основные конструкции языка Python

Лабораторная работа №1 по дисциплине «Парадигмы и конструкции языков программирования».

Цель работы — изучить основные конструкции языка Python и реализовать решение биквадратного уравнения с применением процедурной, объектно-ориентированной и функциональной парадигм программирования.

## Задание

Разработать три консольные программы для решения биквадратного уравнения:

```text
A*x^4 + B*x^2 + C = 0, A != 0
```

Программы должны:

- принимать коэффициенты `A`, `B`, `C` из командной строки;
- запрашивать отсутствующие коэффициенты с клавиатуры;
- повторять ввод, если значение коэффициента задано некорректно;
- вычислять дискриминант `D`;
- находить только действительные корни уравнения;
- выводить коэффициенты, дискриминант и найденные корни.

## Структура проекта

```text
PKYAP_Lab1/

```

- `roots_proc.py` — процедурная реализация с использованием функций;

- `roots_functional.py` — функциональная реализация с использованием `NamedTuple` и сопоставления с образцом `match`.
